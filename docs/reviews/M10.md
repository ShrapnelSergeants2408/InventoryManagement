## Decisions made while building (within the spec)

- **The restore in setup doesn't ask for the PIN.** The tablet is empty and the mentor set the PIN a minute earlier, so there's nothing to protect yet. Restore later (F17) still needs it.
- **"Start empty"** uses the starter catalog's 9 suppliers and 12 categories (with their subcategories), as the mockup describes ("Categories and suppliers only").
- **The recovery-code button now says Next** (setup no longer ends there).
- **The Ready screen** for a restore offers Open count-in and Go to inventory; for an empty start, Add the first item and Go to inventory.
- **Precache:** `.woff` fallbacks left out (Chrome uses woff2); the 1.1 MB scanner `.wasm` included (M8 open item), so scanning works offline even where the native detector is missing.
- **App icons** are the team logo at 192 and 512 px (`public/icons/`), purpose "any". No maskable icon: Android shows the round logo on a plain background.
- **The temporary boot-time seed load (M2–M9) is gone.** Tablets set up before M10 keep working: they already have a PIN and a setup time.
