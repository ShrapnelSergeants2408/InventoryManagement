## Details I filled in (for Dan to confirm)

- (a) **The app can't add Google Drive to the iPhone's file sheet.** That list is iOS's; Drive appears in it only when the Drive app is installed, signed in and switched on in Files › Browse › ⋯ › Edit. This change gives helpers a way that doesn't depend on it: open the folder in the browser, download the kit to the phone, choose it from Downloads.
- (b) **"Scan the kit QR" means the Kits folder QR on the tablet** (Helper devices, M27). A kit is far too large for a QR code, so the code opens the folder and the helper downloads the kit there.
- (c) **On first launch the helper doesn't know the Kits link**, so Open Google Drive goes to drive.google.com; the QR code goes straight to the right folder. After a kit has been opened, the button says Open the Kits folder and goes there.
- (d) The scan opens the link in a new tab only when the helper taps **Open the Kits folder**, so the browser doesn't block it.
- (e) The first-launch camera permission prompt appears the first time Scan is tapped. If the camera is refused, the dialog says to use the phone's Camera app.
- (f) The filter removal from M27 stays; it does no harm, and the "not a kit" message covers a wrong file.
- (g) **Not tried on an iPhone**: the real iOS download flow (Drive app or Safari saving the ZIP to Downloads) and iOS's camera permission for a home-screen web app are untested here.
