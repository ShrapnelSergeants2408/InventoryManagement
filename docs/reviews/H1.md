# H1: strip and rebrand

**Branch:** `h1-strip-rebrand` from `main` (`3ae9912`) · **SPEC:** v2.0 §15 H1 · **App version:** 0.1.1 · **Date:** 2026-11-02

## What was built

H1 turns the FRC shop inventory into a local-only household list, ready for H2 (areas, spots, bins, seasons).

**Removed (code, tests, styles):**
- **Purchasing:** vendors, prices, suppliers, order lists, placed orders, receipts, spending, budget, price import.
- **Helper devices:** count kits, counts files, import, pending items.
- **Count-in.**
- **The mentor PIN:** gate, lock, recovery code, PIN pad.
- **First-launch role choice and the starter catalog** (`seed/`).
- **Stock status:** short and low spares.
- **The FRC logo, browser checks and docs:** reviews, mockups, history, FRC proposals (D9).

**Kept and reshaped:**
- **Item:** id, name, category, subcategory, location (flat, until H2), quantity, barcode, notes, photo.
  - `onHand` became `quantity`.
  - `unit`, `desired`, `spares`, `source`, `lastCounted`, `countedBy` and vendors are gone.
- **Database:** a new database `home-inventory` at schema v1 (D1). It has no upgrade code from the FRC app, and keeps the "older copy refuses a newer database" guard.
- **Ids:** `it-` + 8 characters. QR payload `hhi:<id>`. Old `2408:` labels aren't recognized.
- **First launch:** **Start fresh** (13 household categories from SPEC §3) or **Restore a backup file**.
- **Screens:**
  - Inventory: search, recently viewed, category/location filters, Select and Move.
  - Item detail and editor: quantity stepper, no vendors, units or PIN.
  - Scan: typed or camera; an `hhi:` label; product barcodes; locations by name.
  - Labels: 5163 shows the category instead of a part #.
  - More: Categories, Locations, Backup & restore, Settings, About.
  - Settings: backup reminder only.
  - Backup & restore: no helpers or price import.
- **Delete, restore and list renames** ask to confirm but need no PIN (SPEC §6).
- **Rebrand:**
  - "Hiebert Home Inventory" / "Home Inventory" in the manifest, title and backups.
  - iPhone home-screen meta tags and a 180 px `apple-touch-icon`.
  - Placeholder box icons.
  - Portrait orientation.
  - Backup file names `home-inventory-backup-…`.
  - iPhone wording: "phone" for "tablet"; Safari camera settings; save to Files or iCloud Drive.

## Details I decided (confirmed)

Dan, 2026-11-02: "decisions a-h accepted."

- **(a) Interim item model.** H1 keeps the FRC flat location list (with name-based location QR codes) until H2 replaces it with Area › Spot › Bin and `hhi:sp-`/`hhi:bn-` labels.
- **(b) Interim backup format.** `inventory.csv` (id, name, category, subcategory, location, quantity, barcode, notes, photo_file), `locations.csv`, `categories.csv`, `manifest.json`, `photos/`. H2 moves to the SPEC §7 files and must still read this layout.
- **(c) Count-in is gone, not repurposed.** SPEC v2.0 has no count-in. Pack and Unpack (H5) take its place.
- **(d) Backup reminder:** default 30 days, 0 turns it off, at most 90.
- **(e) Avery 5163 item labels** print name, location and category (the third line was the part #).
- **(f) Look:** colours and fonts unchanged; the brand colour and real icon come with the H3 mockups. The placeholder icon is a storage box on the current dark brown.
- **(g) `money.ts` and `url.ts`** are kept although nothing uses them yet: H6 needs them for value and manual links, and their tests still run.
- **(h) Version** `0.1.0-h1`. First built as `2.0.0-h1`; Dan, 2026-11-02: "since this is a new build lets reset the version number to 0.1-h1". npm needs three numbers, so `0.1.0-h1`. Then Dan, 2026-11-02: "remove the h value and use its number as the 3rd position", so H1 is `0.1.1` (H2 `0.1.2`, and so on).

## Not done here (on purpose)

- **CSS** for removed screens (orders, count, helper, import) was deleted; leftover rules in `app.css` (e.g. `.lockpill`) are cleaned up in H3 when every screen is restyled.
- **Deploy:** `.github/workflows/deploy.yml` is unchanged. On this fork, Actions shows no runs and GitHub Pages isn't set up, so **nothing is published**. To try H1 on an iPhone before H4, turn on Actions and Pages (Settings › Pages › Source: GitHub Actions); the app would then be at `https://dhiebert-whs.github.io/HouseholdInventory/`. H4 moves hosting to Cloudflare.

## Phone check (once it's published)

1. On each iPhone, open the address in Safari, then Share › **Add to Home Screen**. The icon and name read "Home Inventory".
2. Open it: **Start fresh** → **Add the first item**. Add a decoration with a new location and a photo.
3. Labels: print a QR label for it (Share › Print, or Save to Files). Scan it from the Scan tab; it opens the item.
4. More › Backup & restore › **Full backup**: save to Files. On the other phone, set up with **Restore a backup file** and pick it.
