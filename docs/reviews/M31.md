## Details for Dan to confirm
- (a) **The limit applies only while searching or filtering.** That is when every matching group opens by itself. Browsing draws what you open, as before; cutting it off there would hide the categories below a big open one. A very large category opened by hand (say 600 vendor parts in Misc) still draws all its rows.
- (b) **100 rows a page**, about what the 129-item starter catalog draws for a one-letter search today, so nothing gets slower than it is now.
- (c) **Headers after the 100th row are left out until Show more** (a header is never shown without its rows). The footer and Select all shown still count every match, and **Select all shown** still selects every match, including those not drawn yet.
- (d) **Update checks:** on coming back on screen at most every 30 minutes, every hour while on screen, and only when online. Check for updates waits up to a minute for a new version to download.
- (e) **Check for updates is its own row in More › About**, under App version, not a button inside the version row.
