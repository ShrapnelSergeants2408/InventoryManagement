## Findings from reading the code

1. **Fixed before commit:** `bundle.ts` re-parsed the whole CSV a second time to get photo paths. The paths are now passed through from the first parse.
2. **Accepted, noted:** CSV cells starting with `=`, `+`, `-` or `@` aren't escaped for Excel ("formula injection"). Escaping would change the data and break the exact round-trip. The risk on a team tablet is negligible.
3. **Accepted, noted:** the importer accepts US dates (`10/17/2026`) and stores ISO, because Excel rewrites ISO dates when a CSV is re-saved. A barcode Excel turned into `6.35964E+11` is rejected with a clear message, since the digits are already lost.
4. **For M2:** GitHub Pages serves the app from a sub-path. `base: './'` is set; the router should use hash URLs so a reload never 404s.
