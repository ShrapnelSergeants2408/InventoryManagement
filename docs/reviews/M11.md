## Findings

1. **Panel chip wording (not changed).** The panel's stock chips read "Short" and "Low spares". The quick-filter row and F5 say "Short only" and "Low spares only". This was the same before M11, and F5's wording change came with v0.8 ("Red only · Yellow only" → "Short only (red) · Low spares only (yellow)"). Left as is: it isn't the order, and the M2 check finds the chip by "Short". Change it if Dan wants the same words in both places.
2. **Check script, while writing it:** the first runs failed in first-launch setup. The setup line copied into the new script had lost an escape (`/\s+/g` instead of `/\\s+/g` inside a template string), so the button lookup removed every letter "s". That was fixed in the script, and the app wasn't involved. The script also uses its own ports (4331 / 9347), because 4329 and 9344 are already used by another check.
