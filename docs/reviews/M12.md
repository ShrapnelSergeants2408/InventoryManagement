## Findings

1. **Restoring the starter catalog as a backup now replaces the tablet's categories.** This is correct under Q5: a list file in a backup replaces that list. It's a change from v0.7, where the seed had no `categories.csv`. On an existing install, restoring the starter catalog puts back the §11 categories. That's the intended way to move an old install to the new list.
2. **Check-script expectations:** M10 first failed 3 checks that still expected 12 categories. The app's output (11) was right, so the expectations were updated. No app change.
3. **`SEED_FILE` is unused.** It's exported from `src/io/seed.ts`, and nothing reads it. It was kept and updated, since removing it isn't part of this milestone. It could be dropped later.
4. **`docs/START-HERE.md`** still describes the 2026-10-17 seed. It's the Stage 4 kit's instructions (history), so it wasn't edited.
5. **Not covered by a check:** restoring a hand-edited file through the UI. The fix is in the restore planning and is unit-tested end to end through `readRestoreFile` → apply.
