## Details I filled in (confirmed by Dan 2026-10-29: "accept a-e")

- (a) **Uncounted means blank last_counted**, the same test as the order-list banner (F12). An item stays NOT COUNTED after its on hand is changed with − / + or by receiving parts, because neither counts as a count (F3, F31). Saving it in count-in, adding it as a new item, or importing a helper count makes it counted.
- (b) **Short only / Low spares only leave uncounted items out**, so the filter counts match the chips. **Needs order** still includes them, as the order list does.
- (c) **Count-in's own screens are unchanged.** "After saving: …" and the group summary describe the count just made, so they show SHORT / LOW SPARES / OK.
- (d) **The toast has no OK button any more.** Any tap anywhere hides it (and still reaches the button underneath), or it goes after 6 seconds as before.
- (e) **On the Scan tab the result panel still covers the lock button** while it's open, as before M21. The lock is back as soon as the panel closes (Done — scan next).
