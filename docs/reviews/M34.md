# M34 review: photos stored a batch at a time (SPEC v0.29)

**Reviewed:** branch `m34-kit-photo-batches`, from `main` after PR #56 (M33). Checked against SPEC v0.29. App version 1.7.3. **Date:** 2026-11-17 CST

## Request
Dan, 2026-11-17: helpers "have been unable to access the google drive using the qr codes or the connect to google drive button. but more importantly the helpers with the updated images aren't opening." On an Android phone the kit was chosen, then: "Couldn't open the kit on this device: photos.bulkAdd(): 1533 of 1533 operations failed. Errors: UnknownError: Error preparing Blob/File data to be stored in object store". Drive "says the drive is inaccessible". Kit supplied: `Mechanical_3_Helper (1).zip`. Then: "go ahead, fix restore in the same PR".

## Cause
Not M32. The kit is fine: 13 MB, 1,533 photos (1,527 JPEG, 6 PNG), the largest 27 KB, and `readCountKit` reads it cleanly. Joining stored every photo in the one transaction that replaced the helper's inventory (`replaceAll`), and Chrome on Android refused that many photo Blobs in one transaction. Kits worked before M30 because the starter catalog has 128 photos; the vendor catalog photos took it past what the phone accepts.

`replaceAll` is also how **Restore** (F17) and **Restore a backup file at setup** (F22) store photos, so a full restore of the 1,533-photo inventory on the Android shop tablet would have failed the same way. That path had never been run at this size on the tablet.

## Not changed: Drive access
The QR codes and buttons only open the folder links saved on the tablet; whether the student gets in is up to Google. What was found (through Dan's connected account, read only):
- The **Counts** folder is in a shared drive, shared with named people only (mostly `@hazelwoodschools.org`). Several students are Viewer or Commenter, which can't upload counts.
- The **Kits** folder (`1wqNtLKSyquRtKK67dEZydkNiCKP_IYGH`) wasn't visible to that account at all.
- On Android a Drive link opens the Drive app with its default account; a phone whose Drive app is on a personal account gets "inaccessible". A school Workspace may also stop students opening folders owned outside the school.
