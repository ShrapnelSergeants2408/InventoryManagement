## Details I filled in

- An empty restore needs a **list file**, not a ZIP as such: a bare ZIP holding only an empty `inventory.csv` is refused, because it would only empty the tablet.
- The missing-photo note keeps the old line listing the ids, so the files can be found and put back in the ZIP.
