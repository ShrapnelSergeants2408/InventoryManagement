## Details I filled in (confirmed by Dan 2026-10-29, except (c))

- (a) **The PIN is asked when the form opens and again on Save if mentor tools relocked in between.** The form doesn't close on relock, so a long order being typed isn't lost.
- (b) **The order date can't be after today** in the date picker.
- (c) ~~**Typed lines** always have pack size 1 and unit "each".~~ **Changed by Dan (2026-10-29):** "allow for different pack sizes and units on typed lines". A typed line now has a Unit box (blank means "each") and its own pack size; received counts units. Built on branch `m19-details-confirmed`: `typedLine` takes a pack size and unit, the form enables Pack size and adds Unit on typed lines. Unit test and two `m19-ui-check` checks added (37/37).
- (d) Receiving can't take more than is still due on a line. An over-delivery is added to on hand by hand (F3), with Edit to raise the packs.
- (e) Recording from a **named list** removes every ordered item from that list, including an item added with + Add line that was also on the list.
- (f) **Placed orders** has All / Open for now. The date ranges and spending summary come in M20.
- (g) Viewing a PDF receipt opens it in the browser's PDF viewer in a new tab.
