## Details I filled in (for Dan to confirm)

- (a) **A subcategory limit is one list per category**, so a helper can hold the whole of Electrical and only Wheels of Mechanical.
- (b) **Items directly under a category** (no subcategory) get a "No subcategory" box, shown only when the category has such items. Without it those items would belong to nobody.
- (c) **Subcategories nobody counts** are flagged in the coverage list ("nobody has Belts") so a category isn't half counted by mistake.
- (d) **An item in another subcategory of the helper's category counts as "outside the helper's groups"** (shown to the mentor at import), the same as any item outside its groups.
- (e) **Older helper apps** ignore the limit and show the whole category; they still send correct counts. Every device should be on 1.4.0 before the count.
- (f) **A helper limited to a subcategory that is later deleted:** the card says so; editing the helper takes it off. A helper left with none of its subcategories is taken off the category.
- (g) Count-in's start screen still lists which helpers have a category by name only, without the parts.
- (h) Helpers that count **locations** are unchanged.

- (i) **The iPhone picker is not verified.** I can't open an iPhone's file sheet here. The only thing in the app that shapes it is the `accept` filter, which I removed; it hadn't changed since M16b, so it may not be the cause. The other usual cause is on the phone: Files › Browse › ⋯ › Edit must have Google Drive switched on (it needs the Drive app installed and signed in). Please test on the iPhone; if Drive is still missing, say what the sheet shows.
- (j) Without the filter, any file can be picked; a wrong file is refused with a clear message (a backup, a counts file, anything else).
- (k) Import counts on the tablet still has the filter (Android Chrome's picker includes Drive).
