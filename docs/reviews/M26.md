## Details I filled in (for Dan to confirm)

- (a) **Links, not folders.** The app can't open a folder picker or choose the download folder on Android. The buttons open the Drive folder in a new tab (the Drive app if installed).
- (b) **Only https links** are accepted, so a typo or a `javascript:` address can't be saved or arrive in a kit.
- (c) **A helper gets the links only with a kit** made after they were set. A kit made earlier has none, so those helpers show no buttons until their next kit. The first kit can't carry them to a helper that has no kit yet; the QR code on Helper devices covers that.
- (d) The QR code is for the **Kits** folder only (what a student must find first). The Counts folder is a button.
- (e) The links are device settings (like the other settings), so they are not in a backup and a restored tablet needs them typed again.
- (f) I did not check that the link really is a Drive folder, only that it is an https address.
