## Details I filled in (for Dan to confirm)

- (a) **"In the future" means more than an hour ahead** of the tablet's clock. Less than that is normal drift between devices, so a backup shared from a phone a few minutes fast doesn't trip the reminder.
- (b) **A link that isn't a web address is left blank, not refused.** The rest of the backup restores, and the confirmation lists up to five such links ("and n more" after that). A bare address like `www.revrobotics.com/x` gets `https://`, as the editor does.
- (c) **The Windows-1252 fallback covers backup ZIPs, not count kits or counts files.** Those are always written by the app, in UTF-8.
- (d) **The PIN pad and the code that asks for the PIN are tested in the browser, not with unit tests.** Unit tests would need a DOM test library added to the project; the browser check tests the same behaviour in real Chrome.
