## Findings

1. **Fixed while building: the shared-group warning came back on every edit.** Editing a helper that already shared a group (accepted when it was added) asked again each time it was saved, even to change only the name. It now asks only about groups the edit adds. Found by the browser check.
2. **Fixed while building: an error message.** Groups that are all gone from the list said "Choose at least one category"; it now says some aren't in the list any more.
3. **Earlier checks updated for intended changes:** M3 (a new item's `last_counted` is now a date-time), M9 (two count-save checks), M5 (its fixture wrote a date-only value straight into the database, which v3 never holds; restore rightly made it midnight), M15 (schema numbers 3 and 4 instead of 2 and 3).
4. **Check-script mistakes, fixed while writing:** clicked the first card's Edit instead of the named helper's; added locations behind the app's back without a reload; the round-progress expectation counted a count from before the round; a thumbnail made by v3 just before the rollback reload. Each is explained in the script.
5. **Kept as is, worth knowing:** the kit holds every item, not only the helper's groups, because §18.3 lets a helper find any item by search or scan. Removing a category leaves it named on helpers that count it; the card says "No longer in the list" and Send refuses until the helper is edited.
6. **Not built here (by the plan):** joining with a kit, helper mode and the counts file (M16b); Import counts, pending items and undo (M16c). The new tables stay empty until then.
